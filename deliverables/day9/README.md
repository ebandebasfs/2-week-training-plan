## Concurrency proof

Full write-up with real output at `deliverables/day9/files/concurrency-proof.md`. Summary:

```
RUN 1:  Customer A -> 201   Customer B -> 409   (123ms)
RUN 2:  Customer A -> 201   Customer B -> 409   (51ms)
RUN 3:  Customer A -> 201   Customer B -> 409   (48ms)
RUN 4:  Customer A -> 201   Customer B -> 409   (48ms)
```

4/4 identical, deterministic because of the row lock, not a coincidence.
Proof script creates its own isolated slot + two customers and tears them
back out; verified zero residue in the DB after every run. Never touches
Day 1 seed data or Day 6 bench data.
